right sidebar mein "Created at" dikhta hai. Ya mujhse bolein — main Shopify connector
se saare products ki exact `createdAt` timestamps ki list nikaal doonga. Kuch products
`2025-11-27` se live hain, jo strong priority proof hai.

## D. Capture karne ka sahi tareeka

1. **Full-page screenshot** — URL bar aur system clock frame mein hona chahiye.
   Chrome: `Ctrl+Shift+P` → "Capture full size screenshot"
2. **Archive turant** — `https://web.archive.org/save/<URL>` har page ke liye.
   Ye third-party timestamped proof hai, aapke apne screenshot se zyada weight
   rakhta hai.
3. **Screen recording** — pura site ek continuous scroll mein, bina cut ke.
4. **Image forensics** — agar wo aapki hi image files hotlink ya re-upload kar rahe
   hain, image ka URL note karein. Agar aapke Shopify CDN
   (`cdn.shopify.com/s/files/1/0702/1789/2058/…`) se direct serve ho rahi hai, to
   ye **open-and-shut case** hai — server logs bhi proof denge.
5. Files ko `ev-01.png`, `ev-02.png` … naam dein, table se match karke.
