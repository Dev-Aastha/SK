# Notice 3 — Google Search Removal

Google ke paas alag-alag forms hain. **Dono file karein** — copyright aur
trademark ke raste alag hain.

## 3A. Copyright (DMCA) removal

**File at:** https://support.google.com/legal/troubleshooter/1114905 →
"Web Search" → "Copyright"

Form mein ye bharein:

| Field | Value |
|---|---|
| Your relationship to the material | Owner / Authorised representative |
| Copyrighted work description | *(neeche wala paragraph paste karein)* |
| Location of authorised example | `https://www.devaastha.com/products/[HANDLE]` |
| Infringing URLs | *(har infringing URL alag line par)* |

**Copyrighted work description — ye paste karein:**

> Original product photographs and original product descriptions created by or for
> Dev Aastha and first published on https://www.devaastha.com from
> [EARLIEST PUBLICATION DATE] onwards. The reported URLs reproduce these
> photographs and descriptions verbatim, without licence or authorisation, as part
> of a wholesale clone of our commercial website.

**Infringing URLs — ek per line, evidence log se:**
```
https://vashome.shop/categories/gifts-under-999
https://vashome.shop/[...]
https://vashome.shop/[...]
```

⚠️ Sirf wahi URLs daalein jinke liye aapke paas matched original + screenshot hai.
Bina verify kiye URL daalne se poori request reject ho sakti hai.
